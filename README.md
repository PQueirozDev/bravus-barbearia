# Bravus Barbearia

Landing page responsiva de uma barbearia, feita com HTML, CSS e JavaScript, usando Vite.

Inclui apresentação, serviços e preços, equipe, contato e uma simulação interativa de agendamento. As informações são ilustrativas; o formulário não envia dados nem efetua reservas reais.

## Executar localmente

Requer Node.js 20.19+ ou 22.12+.

```sh
npm ci
npm run dev
```

## Produção

```sh
npm run build
npm run preview
```

A versão de produção é gerada em `dist/`. As fontes (Google Fonts) e imagens (Unsplash) dependem de conexão com a internet.
